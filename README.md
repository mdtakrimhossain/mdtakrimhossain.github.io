# mdtakrimhossain.github.io

Personal academic site for Md. Takrim Hossain. Plain HTML and CSS, served
directly by GitHub Pages. No build step, no folders — every file sits at the
top level of the repository.

## Files

- `index.html` — homepage: photo, bio, research interests, contact links
- `research.html` — current work, studies and reports, policy briefs, commentary
- `experience.html` — positions held, and leadership
- `education.html` — degrees and results
- `style.css` — all styling for all four pages
- `profile.jpg` — headshot (add this)
- `md-takrim-hossain-cv.pdf` — CV (add this)

## Editing

Open any `.html` file in a text editor, change the text between the tags, save,
and open the file in a browser to check it. Upload the changed file to the
repository and the live site updates within a minute.

Placeholders still to fill are marked `TK` — currently in `research.html`, and
the Google Scholar and LinkedIn URLs in `index.html`.

The header nav and the footer are repeated in all four files. Change a nav
label or the footer year in one, change it in the other three.
